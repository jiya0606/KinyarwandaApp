# KinyarwandaApp
I interned at the Frugal Innovation Hub, Santa Clara University under Dr. Silvia Figueira for this project. I led a small team of high school students to develop a mobile app with interactive games to teach African students English/French. I designed the games, collaborated with and adapted to feedback from teachers in Senegal/Rwanda, developed the frontend in React Native, integrated the frontend with backend using REST APIs, and deployed the app in Senegal and Rwanda. The team consisted of me on the app design and frontend, 2 students on website development, and 2 on backend. This repo contains the code I wrote for the games I designed.
